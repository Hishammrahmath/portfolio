MatchIQ

Football websites show possession and shots. MatchIQ shows when a match swung. It scores every minute of all 104 FIFA World Cup 2026 matches and flags the turning points.

  • Event-weighted momentum model in pandas over rolling 5-minute windows, built on 4 relational CSV datasets.
  • Turning-point detector that flags momentum swings, links the events nearby, and removes overlapping detections. Covered with pytest.
  • Fact-only explanations for fans, players, and coaches: momentum shifts near an event, never because of one.
  • Static data export so the dashboard loads instantly on Vercel, with no server to wake up.
  • Python
  • pandas
  • FastAPI
  • Next.js
  • TypeScript
  • Plotly
  • pytest
  • Vercel

WindWalk

DemonHacks 2026 was a 24-hour hackathon hosted by the DePaul Computer Science Society and Upsilon Pi Epsilon, sponsored by Microsoft. The theme was Loop Life: find a problem in Chicago's Loop and build a fix.

The Loop's skyscrapers turn winter wind into tunnels, and more than 1.5 million pedestrians pass through each week. Most don't know about the Pedway, a 5-mile underground network connecting more than 40 blocks. WindWalk combines live weather data with the Pedway to find the most comfortable route. Our goal was simply to leave with a complete project. We left with 1st place out of 31 teams, at my first hackathon.

  • Worked across the stack: FastAPI backend, Dijkstra-based routing, OpenWeatherMap integration, and the React Native + Mapbox app.
  • Route costs change with live weather, so the best path in a snowstorm differs from the best path in July.

Hardest part: the Pedway has no live map or navigation, only static maps. We cached Pedway routes and built rerouting so people wouldn't get lost underground.

Built with Buck Stevenson, Sameer Akhtar, Jenna Abuzerr, Aiana Kurumshieva, and Nurdan Zholonova.

  • Python
  • FastAPI
  • React Native
  • Mapbox
  • OpenWeatherMap
  • Dijkstra
